Interactive tools

Single-file, offline, no dependencies and no tracking. Open them straight from the repository (tools/) or download them — each one is a self-contained HTML file you can read in five minutes and edit to fit your own project.
Section 02

Prompt anatomy builder

Fill the six parts of an instruction that an agent can actually execute, see it assemble, and get a hint for the part you left out. Loads three worked examples: bug fix, failing test, diff review.

 Section 01 · 02

Context budget calculator

See where a context window goes — system prompt, rules file, history, files, thinking room — and what "context rot" looks like before you hit the limit.

 Section 05

CI pipeline visualiser

Inject a defect (a pasted key, a destructive migration, a hallucinated dependency, a weakened test) and watch which gate catches it — or which one lets it reach production.

 Section 07 · 13

Small-product cost calculator

Cost per request, per month, by driver: model tokens, compute, database, storage, GPU jobs, CI minutes. Every price is an editable placeholder — replace them with current published rates.
