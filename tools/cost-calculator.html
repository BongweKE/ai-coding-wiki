  • Input tokens dominate. The whole context is re-sent on every turn, so context hygiene is the biggest lever you have.
  • Caching is a multiplier. Even a 25% hit rate removes a quarter of model spend — but only if the cache key cannot mix domains or tenants.
  • Batching beats retrying. Batch embeddings and migrations in groups instead of one network round-trip per row.
  • Size the GPU to the job. Text embeddings do not need the largest accelerator on the market. Idle capacity is still billed.
  • Measure cost per successful outcome, not per request — a cheap pipeline that fails is the expensive option.
