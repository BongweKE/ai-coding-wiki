Context Budget Calculator

A context window is a budget, not a bucket. Everything the model sees in one call competes for the same space, and quality degrades as the window fills. Drag the sliders to see where your tokens go.
  • Rule of thumb, not a law: keep the noisiest parts (history, full-file reads) small and the durable parts (rules, task) tight.
  • Token counts vary by tokenizer; treat every number here as an estimate for planning, not an invoice.
  • A 1M-token window does not mean you should use it — long inputs are slower, pricier and easier to get wrong.
