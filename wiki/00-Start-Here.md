> **Section 0 · Start Here** — What AI coding actually is, what the tools are, and a workbench that works.

*5 lessons.*

## By the end of this section you can

- Decide which path through this wiki is yours, and why.
- Explain what an AI coding agent is, in your own words, without jargon.
- Have a working workbench — git, the GitHub CLI, a runtime, an editor, one agent — with secrets stored properly.
- Open your first pull request from the terminal.
