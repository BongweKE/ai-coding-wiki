> **Section 16 · Reference** — Cheat sheets, templates, the mermaid cookbook and the link index.

*6 lessons.*

## By the end of this section you can

- Look up the git command that saves you, including the six ways to undo.
- Find the GitHub CLI command for the question you actually have.
- Copy a template for an ADR, an SOP, an AGENTS.md, a pull request, a CI workflow or a skill.
- Render a diagram that works on the first try.

### [Git Cheat Sheet](16-Git-Cheat-Sheet)
`beginner` · ~10 min — Grouped commands with one-line explanations: setup, everyday, branching, undoing (restore, revert, reset, reflog), inspecting (diff, log, blame, bisect), remotes and stashing.

### [GitHub CLI Cheat Sheet](16-GitHub-CLI-Cheat-Sheet)
`beginner` · ~10 min — Commands grouped by task: repos, issues, PRs, checks/actions, releases, secrets/variables, projects, auth.

### [Railway And Neon Cheat Sheet](16-Railway-And-Neon-Cheat-Sheet)
`intermediate` · ~12 min — Railway: link, up, logs, variables, environments, services, redeploy, and the one-line status checks worth memorising.

### [Mermaid Cookbook](16-Mermaid-Cookbook)
`beginner` · ~15 min — You do not need to remember Mermaid syntax.

### [Templates](16-Templates)
`intermediate` · ~15 min — Copy-ready templates: AGENTS.md skeleton, ADR (MADR-style), SOP, PR template, issue forms (bug/feature/task), a CI workflow for Python and one for Node, CODEOWNERS, a SKILL.md, a lesson entry, an eval-set description, a runbook, a security checklist, a release-notes entry.

### [Link Index](16-Link-Index)
`beginner` · ~10 min — Every external link used in the wiki, grouped by section and topic, with a one-line description.
